# 黄河影像征集核验

本仓库保存该服务的领域资料、事件约定与核验入库实现，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`、`data/sample-batch.json`：可用于联调的中文样例记录与投稿批次。
- `src/`：核验入库服务实现（见下）。
- `tests/`：验证样例、领域约定与各项业务保证。

## 服务结构

- `src/eventStore.js`：追加式事件存储。事件一旦接收，其标识、发生时间和版本不被原地改写；版本号由存储统一分配，并发入库时版本冲突会被拒绝。
- `src/service.js`：入库服务外观，负责批量接收、谱系登记、发布依据冻结、撤回处置、复核路由与恢复推进。
- `src/rights.js`：版权范围、人物同意、地域限制的时点评估（纯函数）。
- `src/lineage.js`：作品当前片段与片段替换链的谱系投影。
- `src/jobs.js`：待办任务日志（授权核验、撤回通知），中断后恢复继续推进。
- `src/validator.js`：基础事件信封校验。

## 业务保证

- **谱系拆分**：投稿进入系统后拆出作品、素材片段、投稿人声明、权利凭证、脱敏版本五类实体，各自携带上游来源（`lineageOf`）。
- **关联提示**：内容摘要相同只产生关联建议（`ASSOCIATION_SUGGESTED`），是否合并由编辑决定（`decideMerge`）。
- **依据冻结**：编辑选择发布用途时（`selectPurpose`），系统把当时有效的版权范围、人物同意和地域限制冻结为发布依据（`BASIS_FROZEN`）；迟到授权与并发入库不改变已冻结的依据。
- **撤回语义**：撤回只阻止之后的新使用；已经发生的合规发布保留原依据并追加处置记录（`DISPOSITION_RECORDED`），同时登记撤回通知任务。
- **分角色复核**：涉及未成年人的片段交给 `minor_protection`，包含受限地理信息的片段交给 `geo_security`，复核未通过前发布被拦下。
- **批量容错**：一次批量接收即使混有坏记录也保住其余作品；同一请求编号重放返回原结果；实体编号相同而摘要不同的记录隔离待查（`RECORD_QUARANTINED`）。
- **中断恢复**：未完成的授权核验与撤回通知在任务日志中保持待办，服务重开后由 `resume()` 继续推进。
- **成片可解释**：`explainPublication` 说明任一成片为何获准、替换过哪些片段、哪些合作方尚未确认。

涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 本地检查

```bash
node --test
```

## 测试与构建

测试命令：

```bash
npm test
```

编译或构建命令：

```bash
npm run build
```

上述命令均可在单个 Linux 应用容器内执行，不需要另行启动外部服务。
